**Composio API Research Agent**
This repository contains an autonomous research agent built to analyze 100 SaaS applications for Composio. The agent evaluates API surfaces, auth methods, self-serve vs. gated access, and buildability verdicts for AI agent toolkits.

  The final interactive case study summarizing the patterns, verification loops, and the 100-app matrix can be viewed here: Live HTML Case Study (Replace this with your actual Vercel link)

**How the Agent Works**
The agent is built using LangChain and uses a "Plan and Execute" pattern:

  1. Search & Extract: Uses the Tavily Search API to find official developer documentation for each app.
  2. Reason & Structure: Uses OpenAI's gpt-4o to parse the raw documentation and extract the target JSON schema (Auth, Access, API Surface, Verdict).
  3. Verification Loop: A secondary pass cross-checks the output against the evidence URL. If data is missing or ambiguous, it flags the app for human review.
  4. Output: Generates a results.json file containing the structured research data.

**Prerequisites**
Before running the agent, you will need:
  1. Python 3.8+ installed on your machine.
  2. An OpenAI API Key (for GPT-4o reasoning). Get one at platform.openai.com.
  3. A Tavily API Key (for web search). Get a free key at tavily.com.

**Setup & Installation**
Follow these steps to run the research agent locally:
1. Clone the repository:
  git clone
  "https://github.com/YashwanthYS2004/composio-api-research.gitcd composio-api-research"
2. Install the required Python packages:
  bash
  "pip install langchain langchain-openai langchain-community tavily-python"
3. Add your API Keys:
  Open the agent.py file in your preferred text editor and replace the placeholder strings with your actual API keys:

  python
  os.environ["OPENAI_API_KEY"] = "your-openai-key-here"
  os.environ["TAVILY_API_KEY"] = "your-tavily-key-here"

**Running the Agent**
Once the setup is complete, execute the script from your terminal:
  bash
  "python agent.py"

**What to expect:**
--->The terminal will display the agent's thought process as it searches the web and reasons through the documentation for each app.
--->Once finished, it will generate a file named results.json in the root directory, which contains the raw JSON output of the research.

**Repository Contents**
