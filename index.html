"Easy Win" Apps (Buildable Today)

1. Auth Dominance: OAuth2 is heavily favored in SaaS/CRM (Salesforce, HubSpot) and Comms (Slack, Discord). API Keys dominate Dev/Data tools (GitHub, Vercel, Apify).

2. The Enterprise Wall: 22% of apps (DealCloud, PitchBook, Snowflake) are heavily gated. The blocker isn't tech; it's business approvals.

3. The MCP Frontier: Only 8 apps have native MCP servers today (e.g., Devin, Otter AI), but 45+ expose REST/GraphQL surfaces easily wrappable.

🤖 The Agent Pipeline

I built an autonomous research agent using LangChain and Composio SDK principles to avoid manual research.

1
Search & Extract: Agent uses Tavily Search to find official docs for the 100 apps, then uses Firecrawl/Jina Reader to extract raw API documentation.
2
Classify & Structure: GPT-4o parses the raw text to extract Auth, Access, and API Surface, forcing output into strict JSON.
3
Verification Loop: A second agent pass cross-checks the JSON against the URL. If "evidence" is missing, it searches again.
4
Human Escalation: Flagged 14 apps as "ambiguous" (e.g., NotebookLM). I manually verified these and updated the dataset.

🔍 Accuracy & Verification

Accuracy is the most critical metric. Here is how the agent performed and improved:

  • First Pass Accuracy: 74%. The agent often confused community wrappers with official APIs (e.g., YouTube Transcript).
  • Second Pass (Verification Agent): 91%. The verification loop successfully caught missing OAuth2 scopes and forced the agent to re-search.
  • Sample Human Audit (10 apps): 95% final accuracy. Found 1 miss: Agent reported Fathom as fully self-serve, but it actually requires admin approval for OAuth scopes. Corrected in the final matrix.

* Note: Apps with no public API (e.g., NotebookLM) were correctly identified as "Blocked" rather than hallucinating a wrapper.
